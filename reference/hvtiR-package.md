# hvtiR: Install and Check the HVTI R Package Family

Installs, updates and reports, in a single step, on the family of R
packages from the Cardiovascular Outcomes, Registries and Research
(CORR) group of the Heart, Vascular and Thoracic Institute (HVTI) at
Cleveland Clinic. Members are resolved from public GitHub repositories
with 'pak', keeping installations aligned with the source where family
releases land first. Provides a status table comparing installed
versions and source commits against the main branch on GitHub, and a
diagnostic report for environment problems.
