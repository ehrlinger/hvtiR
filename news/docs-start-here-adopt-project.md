* `vignette("start-here")` sets a study up the way `setup()` now works: open the
  study's directory as an RStudio project, run `hvtiR::setup()` with the title
  and Study Tracker ID, and answer `yes` when it asks to adopt the directory. It
  says what to do when `setup()` asks to be run from outside the project, and
  keeps `root =` for a study whose directory does not exist yet.
